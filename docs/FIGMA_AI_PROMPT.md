```
A dark, dense, alive inventory management dashboard called "Motico".

The feeling is a mission control room — not a SaaS template. Every pixel earns its place.
Data is the hero. Numbers breathe. The interface feels like it's monitoring something
in real-time, like a trading terminal or a spacecraft telemetry panel.

Dark background (#0F1117) with layered surfaces (#1A1D26, #22263A). Thin subtle
borders (#2E3247). No gradients. No decorative shadows. No friendly rounded corners.
Sharp, tight, 4px radius max. The aesthetic is Bloomberg Terminal meets Linear app.

Three-column desktop layout at 1440px:21///*
— Left: narrow vertical navigation with icons and labels, collapsible
— Center: dense data table showing inventory (SKU, product name, stock count,
  minimum threshold, status badge). Stock numbers in monospace font, large and prominent.
— Right: a fixed 256px sidebar called "Suggestion Hub" with stacked action cards
  sorted by urgency — red-bordered critical alerts, amber warnings, blue insights.

Top bar: tenant/business selector on the left, global search center, notification
bell on the right. Minimal. Functional. No branding clutter.

Color language is semantic and immediate:
— Red (#FF3B30) for critical stock levels — feels urgent, almost pulsing
— Amber (#FF9500) for warnings — attention without panic
— Green (#30D158) for healthy status — calm confirmation
— Blue (#0A84FF) for informational — neutral, trustworthy

Typography: monospace for all data and numbers (DM Mono vibe), clean sans-serif
for UI labels (Inter vibe). The contrast between data font and UI font creates
a technical, precise character.

The overall mood: you're an operator with full situational awareness. Dense but
not cluttered. Technical but not intimidating. Every element is functional.
Zero decoration. The beauty comes from the precision and the rhythm of the grid.

Think: Vercel dashboard density + Figma's dark mode clarity + Bloomberg's
information architecture. Latin American small business context — practical,
no-nonsense, built for speed on the warehouse floor.
```
